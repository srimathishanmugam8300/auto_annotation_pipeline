# Model Weights

Place runtime model weights in this directory.

- YOLO aliases:
  - `yolov8` -> `yolov8n.pt`
  - `yolov8n` -> `yolov8n.pt`
  - `yolov8s` -> `yolov8s.pt`
  - `yolov8m` -> `yolov8m.pt`
- SAM alias:
  - `sam_vit_b` -> `sam_vit_b_01ec64.pth`

The pipeline can use a direct file path in the JSON config instead of an alias.
